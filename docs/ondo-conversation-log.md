## 3. 컬러 (Espresso + Pale Oak)

**🧑 사용자**
> [컬러 조합 이미지] v2 키컬러랑 세컨드 컬러 이걸로해주라! (Espresso #3C2415 / Pale Oak #DDD9CE)

**🤖 어시스턴트**
- 라이트=페일오크 배경+에스프레소 잉크 / 다크=에스프레소 배경+페일오크 잉크로 토큰 교체. (웜 계열이라 가이드의 쿨그레이와 반대지만 지정색 우선)

**🧑 사용자**
> 라이트 버전일때 배경을 화이트로 해줘 / (중단) 아니야 배경은 그대로 화이트로 해야돼

**🤖 어시스턴트**
- 라이트: 배경 흰색, 페일오크는 카드/서피스에만.

**🧑 사용자**
> 음 세컨드 브라운 컬러(카드 배경) 너무 어두워, 반 정도 더 연하게

**🤖 어시스턴트**
- 카드 서피스 `#DDD9CE → #EEECE7` (흰색과 중간값).

**🧑 사용자**
> 음 좀 더 밝게

**🤖 어시스턴트**
- `#EEECE7 → #F5F4F0`.

**🧑 사용자**
> 버튼 hover할때 어두워져야 / 헤더 탭 간격 넓히고 / 탭 hover시 카드보다 연한 은은한 버튼 배경

**🤖 어시스턴트**
- 버튼 hover `brightness(0.86)`, 탭 간격 확대 + 탭 hover 알약 배경(`--nav-hover`) 추가.

**🧑 사용자**
> 탭 메뉴 Hover박스 상하 패딩 2px 더

**🤖 어시스턴트**
- nav 링크 패딩 `8px → 10px`.

## 4. 히어로 섹션

**🧑 사용자**

**🧑 사용자**

**🤖 어시스턴트**
- 히어로 재구성: 헤드라인/리드/온도카드 삭제, 중앙 정렬, 스크림 제거, 텍스트 밝게, `HeroText.png`(ONDO 네온 워드마크, 투명 PNG) 삽입.

**🧑 사용자**

**🤖 어시스턴트**

**🧑 사용자**

**🤖 어시스턴트**

**🧑 사용자**
> 온도 이미지 크기 줄여줘 (420) → 다 위로 (-8vh) → 서울성수 삭제·더 작게(320)·더 위로(-16vh)

**🤖 어시스턴트**
- 순차 적용.

**🧑 사용자**
