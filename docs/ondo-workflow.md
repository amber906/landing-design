## 🗺️ 전체 흐름 한눈에

```
0. 초기 생성(AI 디자인)
      ↓  복제
1. 디자인 스킬 적용(쿨그레이+틸)  +  텍스트 윤문 스킬 실험
      ↓  컬러 지정
2. Espresso + Pale Oak 컬러 전환
      ↓  실사진 투입 시작
3. 히어로: 배경 사진 + ONDO 워드마크         🖼️ hero / HeroText
4. 헤더: 로고 이미지화, 라이트 고정
5. 메뉴: 이미지 카드 6종                      🖼️ menu-1~6
6. 원두: 큰 이미지 + 리스트                    🖼️ Bean
7. 공간: 클릭 확대 아코디언                     🖼️ 01 / Lounge / 03 / 04
8. 오시는 길: 지도 카드                         🖼️ map
9. 푸터/디테일 마무리
      ↓
10. 다크모드 제거(라이트 전용)
11. 문서 정리 + 3버전 실서버 배포
```

## 🧩 단계별 상세

### Phase 0 — 초기 생성
- **요청**: "카페 랜딩 페이지 제작해줘"
- **작업**: "온도 ONDO" 컨셉으로 원페이지 생성. 딥 파인그린 + 웜 아이보리 + 앰버, 세리프 디스플레이, **추출 온도 슬라이더 인터랙션**, **증기(steam) 캔버스 애니메이션**.
- **이미지**: 없음 (CSS/캔버스로만 구현)
- **요청**: "외부 브라우저에 띄워줘" → 로컬 HTML을 Mac 기본 브라우저로 오픈.

### Phase 1 — 복제 & 스킬 실험
- **요청**: "복제해서 거기서 디자인 디벨롭하고 싶어" → `ondo-cafe-v2.html` 생성(원본 보존).
- **요청**: [Human-Like Web Design 가이드 붙여넣기]
  - **작업**: v2 전면 재설계 — 세리프 제거(Pretendard/Inter), 14px 이상, weight 400/500/700, **쿨 그레이 뉴트럴 + 틸 primary**, 그림자·pill·그라디언트 제거, radius 8~20, 패딩 스케일 정리.
- **요청**: GitHub `im-not-ai`(AI티 제거 스킬) → 원본 복제 반영
  - **작업**: 실제론 **한글 텍스트 윤문 스킬**로 확인. `ondo-cafe-humanized.html` 생성, 대구·buzzword·번역투 등 카피만 자연스럽게.
- **이미지**: 없음

### Phase 2 — 컬러 전환 (Espresso + Pale Oak)
- **요청**: [컬러칩 이미지] "키컬러·세컨드 이걸로" → **Espresso `#3C2415` / Pale Oak `#DDD9CE`**
- **반복 조정**:
  - 라이트 배경은 화이트로 고정, 페일오크는 카드에만
  - 카드 톤 "반 더 연하게" → `#EEECE7` → "더 밝게" → `#F5F4F0`
  - 버튼 hover **어두워지게**, 헤더 탭 간격 넓히고 hover 알약 배경, 탭 상하 패딩 +2px
- **이미지**: 없음 (컬러칩은 참고용, 페이지엔 미삽입)

### Phase 3 — 히어로 (첫 실사진 투입) 🖼️
- **요청**: [카페 테이블 사진] "히어로 배경으로"
  - **🖼️ `hero.png` 삽입** → 히어로 풀 배경(테마 대응 스크림과 함께)
- **요청**: "HeroText 파일 넣어줘" + 헤드라인/리드/온도카드 삭제, 가운데 정렬, dim 제거, 텍스트 밝게
  - **🖼️ `HeroText.png` 삽입** → ONDO 네온 워드마크(투명 PNG)를 히어로 중앙 제목 자리에
  - 투명 여백이 커서 **`HeroText-tight.png`로 크롭** 후 교체 → 간격 12px로 타이트하게
- **조정**: 워드마크 크기 ↓(420→320), 위치 ↑, 에어브로우 삭제
- **요청**: "화면 로드 시 가득 차게" → 히어로 `min-height: calc(100dvh - 헤더)` 풀스크린

### Phase 4 — 헤더
- **요청**: ONDO 옆 "온도" 삭제 / 라이트모드 고정 / 모드 버튼 제거 / 방문예약 작게 → 헤더 축소
- **요청**: "헤더 로고도 이미지로"
  - **작업**: `HeroText-tight.png`를 **CSS 마스크**로 재활용 → 에스프레소 컬러 ONDO 로고 (새 이미지 아님)
- **요청**: 방문예약 → 연한 갈색 세컨더리 → 더 연하게(태그색 `#F5F4F0`), 사이즈 유지
- **요청**: 헤더 하단 stroke 제거 → (그라데이션 실험) → 최종 **반투명 흰색 + blur**

### Phase 5 — 메뉴 (이미지 카드) 🖼️
- **요청**: "메뉴 카드 형식으로, 이미지 넣을 파일 띄워줘" → scratchpad Finder 오픈
- **요청**: [Iceland Cabin 참고] "하단 블러 그라데이션 + 이름·가격, 버튼 없이"
  - **🖼️ `menu-1.png`~`menu-5.png` 삽입** → 3열 이미지 카드. 하단 `backdrop-filter blur` + mask 그라데이션, 이름/가격.
  - 메뉴 매핑: 1 온도블렌드 · 2 예가체프 · 3 브라운슈가라떼 · 4 콜드브루 · 5 제철과일에이드
- **조정**: 블러 영역 위로 확장 / 가격 크게 / 키워드 → 태그박스 / 순서 타이틀→태그→가격
- **요청**: "menu6으로 딸기블렌드"
  - **🖼️ `menu-6.png` 삽입** → **"제철 과일 스무디"** 카드 추가 (가격·태그는 임의 지정)
- **요청**: "온도 블렌드 → ONDO 블렌드", 카드 이미지 위 검은배경 크롭(정사각→6/7), 가격 24px

### Phase 6 — 원두 (큰 이미지 + 리스트) 🖼️
- **요청**: 섹션 타이틀들 가운데 정렬
- **요청**: [Bean 이미지] "왼쪽에 크게"
  - **🖼️ `Bean.png` 삽입** → 원두 섹션 왼쪽 대형 이미지(투명 PNG, 잘림 없이)
  - (중간 실험: 카드 블러로 원두 비치게 → 되돌림)
- **요청**: [Problems 리스트 참고] "카드→리스트 형식"
  - **작업**: 오른쪽을 로스트 **세로 리스트**(라벨/이름/설명 + 구분선)로, dots 제거
- **요청**: 리스트 설명 끝 마침표 삭제

### Phase 7 — 공간 (클릭 확대 아코디언) 🖼️
- **요청**: [Lounge 이미지] "머무는 시간까지 섹션 배경으로"
  - **🖼️ `Lounge.png` 삽입** → 처음엔 섹션 풀 배경으로
- **요청**: [VEXA 아코디언 참고] "상단 타이틀 + 01·02·03·04, 클릭하면 커지는"
  - **작업**: 배경 → **아코디언**으로 전환. 번호+캡션+썸네일, 클릭 시 확대(큰 이미지+제목+설명), 하나만 열림. 이미지 크기 트랜지션.
  - Lounge는 1번에 배치했다가 → **"1번 이미지 2번으로 옮겨"** 지시로 02번으로 이동
- **요청**: "나머지 01/03/04 저장할게" → "됐어"
  - **🖼️ `01.png` / `03.png` / `04.png` 삽입** → 아코디언 1·3·4번 이미지
  - 최종 매핑: **01=01.png / 02=Lounge.png / 03=03.png / 04=04.png**
- **요청**: 01·02·03 설명 줄바꿈 적용

### Phase 8 — 오시는 길 (지도) 🖼️
- **요청**: [지도 이미지] "지도 카드에 카드 비율에 맞게"
  - **🖼️ `map.png` 삽입** → info 카드 안 지도 영역(cover). 가짜 격자·핀 제거.
- **조정**: 지도 카드 배경 50% 연하게 / 태그는 이전 배경색 / **지도 ↔ 텍스트 좌우 위치 교체** / 원두클래스 버튼 색 맞춤 / 섹션 아래 패딩 2배

### Phase 9 — 푸터 / 디테일 마무리
- **요청**: 푸터 "ONDO" 텍스트 → **이미지 로고**(HeroText 마스크, 프라이머리 컬러) / 배경 연한 갈색 → 50% 연하게 / 문구 줄바꿈
- 헤더 방문예약 버튼 톤 통일 등 미세 조정

### Phase 10 — 다크모드 제거
- **요청**: "원본·버전2 다크모드 지우고 화이트 전용으로, 배포에도 반영"
  - **작업**: `@media prefers-color-scheme: dark`, `data-theme` 블록, 모드 토글 버튼·스크립트 제거 → 라이트 전용. (최종본 v2는 이미 라이트 전용)

### Phase 11 — 정리 & 배포
- 프롬프트 히스토리 정리, 대화 로그(.md) 추출
- SEED 디자인 참고 관련 저작권 Q&A, 스킬 문서에서 SEED 언급 제거 버전 제공
- **3개 버전 실서버 배포** (GitHub Pages, amber906):
  - 최종본 이미지 14종 **압축·인라인**(2.3MB)해 자체 완결 파일로 배포
  - 인덱스(갤러리) 페이지 + 원본/스킬본/최종본
- 다크모드 제거분 재배포

## 🧷 반복된 협업 패턴
- **"파일 띄워줘"** → 작업 폴더를 Finder로 열어, 사용자가 지정 파일명으로 이미지 저장 → "됐어" → 코드 연결
- 파일명이 예상과 다르면(예: `herotext.png`로 안내했지만 `HeroText.png`로 저장) 실제 파일명·대소문자에 맞춰 코드 수정
- 참고 이미지(Iceland Cabin / Problems / VEXA / 컬러칩)는 **디자인 레퍼런스**로만 쓰고 페이지엔 미삽입

## 🛠️ 기술 메모 (핵심 트릭)
- **투명 PNG 로고 재색칠**: `background-color + mask-image`로 흰 워드마크를 브랜드 컬러로 (헤더·푸터 로고)
- **카드 하단 그라데이션 블러**: `backdrop-filter: blur()` + `mask-image` 그라데이션으로 아래만 흐려지게
- **아코디언 확대**: `is-open` 클래스 + 이미지 `width/height` 트랜지션, 하나만 열리는 JS
- **풀스크린 히어로**: `min-height: calc(100dvh - 헤더px)`
- **인코딩**: 로컬 서버 제공 시 한글 깨짐 → `<meta charset="utf-8">` 추가
- **배포 자체완결**: 이미지 14종을 리사이즈+JPEG/PNG 압축 후 base64 인라인 → 단일 HTML 2.3MB
